# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability
reporting feature in the repository's **Security** tab. Include reproduction steps, affected
versions, impact, and any suggested mitigation.

Please avoid testing against accounts or data that you do not own. We will acknowledge a complete
report as soon as practical and coordinate disclosure after a fix is available.

## Supported versions

Until the first stable release, security fixes are provided for the latest published version only.
